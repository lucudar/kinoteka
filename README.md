# Кинотека — личный медиаплеер для iPhone в стиле Zona

Приложение на SwiftUI с разделами как в Zona: Главная, Каталог (фильмы и сериалы с фильтрами), ТВ-каналы, Поиск и «Моё» (избранное, «Смотреть позже», просмотренное, история, настройки).

- **Каталог, поиск, описания, рейтинги КП и IMDb, сезоны, актёры, похожие** берутся из [неофициального API Кинопоиска](https://kinopoiskapiunofficial.tech), а без ключа или когда он не отвечает — из поискового индекса Zona (сервер в России, работает без VPN).
- **Раздачи находятся сами, как в Zona**: приложение берёт торренты фильма из индекса Zona (по id Кинопоиска, с уже распознанными озвучкой и качеством) и одновременно ищет по названию и году через [Jacred](https://github.com/immisterio/jacred) (публичный сервер `jac.red`, по умолчанию) или ваш Jackett, показывает качество, озвучку, размер, сиды и сразу включает лучший вариант. Если он не заработал, приложение автоматически пробует следующую подходящую раздачу. Видео идёт через встроенный [TorrServer MatriX](https://github.com/YouROK/TorrServer) без скачивания целиком.
- **Свои источники** тоже работают: magnet-ссылки, ссылки на `.torrent` и info-hash, прямые ссылки на mp4, mkv и HLS (m3u8).
- **ТВ-каналы** — из вашего M3U-плейлиста (по ссылке или из файла): группы, логотипы, избранное и недавние каналы.
- **Плеер** на VLCKit: MKV, HEVC, AC3/DTS, выбор и запоминание озвучки и субтитров, внешние дорожки .mka, синхронизация звука и субтитров, скорость, пропорции, жесты яркости/громкости/перемотки, двойное касание для перемотки на 10 секунд, блокировка экрана, таймер сна, картинка в картинке, продолжение с места остановки и обратный отсчёт до следующей серии.
- **Загрузки**: фильм, серию или сезон можно скачать на iPhone и смотреть без интернета.
- **Субтитры из интернета**: поиск на OpenSubtitles прямо из плеера, вручную или автоматически.
- **Сериалы**: просмотренные серии отмечаются сами, «Смотреть» включает первую непросмотренную серию, сезон можно отметить целиком.
- **Актёры и режиссёры**: на странице человека — его фильмы и сериалы, сгруппированные по ролям, режиссуре и сценариям.
- **Личная главная**: «Продолжить просмотр», «Смотреть позже» и рекомендации по жанрам из вашей локальной медиатеки.
- **Защита данных**: экспорт/импорт резервной копии, автоматический восстановительный файл и возможность навсегда скрыть неудачную раздачу.

Приложение не содержит контента. Для каталога и списка раздач оно, как приложения Zona, обращается к открытому поисковому индексу Zona (`zsolr3.zonasearch.com`) и её постерам (`img2.zonapic.com`); это можно выключить: **Моё → Настройки → Поиск раздач → Индекс Zona**.

## 1. Ключ API Кинопоиска (необязательно)

Без ключа всё работает через индекс Zona. С ключом данные подробнее: названия и даты серий, возрастной рейтинг, трейлеры, фото актёров.

1. Зарегистрируйтесь на <https://kinopoiskapiunofficial.tech/signup>.
2. Скопируйте токен из профиля.
3. В приложении откройте: **Моё → Настройки → Кинопоиск** и вставьте ключ.

Бесплатный тариф — 500 запросов в сутки. Ответы кэшируются на устройстве, поэтому повторные открытия не тратят лимит. Если лимит исчерпан или Кинопоиск не отвечает, каталог на время берётся из индекса Zona.

## 2. Как смотреть

Откройте фильм или сериал и нажмите **Смотреть** — приложение само найдёт раздачи и включит лучшую: выбранное качество (по умолчанию 1080p), живые сиды, дубляж, без экранок и огромных ремуксов.

**Качество и озвучка** выбираются прямо на странице фильма. «Авто» учитывает сеть: на мобильной сети качество ограничивается до 720p, на Wi‑Fi используется настройка пользователя. Приложение запоминает удачные раздачи, трекеры и выбранную аудиодорожку. Если выбрать другое качество у начатого фильма, «Продолжить» откроет другую раздачу с того же места (у сериала — с той же серии). В плеере качество меняется на ходу: **⚙︎ → Качество** — новая раздача подключается, пока играет текущая.

Кнопка **Раздачи** показывает все найденные варианты, как в Zona: фильтры по сезону и качеству, сортировка по сидам, качеству, размеру и дате, отметки HDR и «Экранка», озвучки и дорожки. В строке поиска можно задать свой запрос (например, оригинальное название), а внизу — добавить свою magnet-ссылку или ссылку на видео. Выбранная раздача запоминается: в следующий раз **Смотреть** включит её же.

### Что нового в 0.12.2 — данные торрента находятся, а не «нет пиров»

Почему раньше часто появлялось «Не удалось получить данные торрента: нет пиров или ссылка неверна» и помогало только «Повторить»:

- **Пиры из приложений Zona не отдают данные торрента** (список файлов, который для magnet-ссылки присылают сами пиры): их клиент вообще не поддерживает такую передачу — свои торренты Zona берёт со своих серверов. Раздачи из индекса Zona бывают почти целиком из таких пиров — подключено 10–30, а данные отдать некому. Отдают их только обычные клиенты (qBittorrent, uTorrent, Transmission и другие).
- **Движок подключался к пирам медленно**: не больше 25 попыток одновременно и 10 новых в секунду, ожидание ответа до 20 с — в среднем меньше одного нового пира в секунду, даже когда известны сотни.
- **Движок iOS собран со старой версией торрент-библиотеки**: если первый поиск пиров в DHT сразу после запуска пришёл пустым, следующий был только через 5 минут.
- **Кинотека сдавалась слишком рано**: первой раздаче давалось 10 с, запасным — по 18 с, и каждая следующая закрывала предыдущую вместе с найденными пирами. «Повторить» помогало, потому что последняя раздача всё это время продолжала искать.

Что изменилось:

- **Движок собирается из исходников TorrServer MatriX.147.2 с правками Кинотеки**: библиотека настольного TorrServer (повторный поиск в DHT через 15 с вместо 5 минут), до 80 попыток подключения одновременно и 40 новых в секунду, ожидание ответа 2–10 с. В проверке на 32 раздачах данные торрента обычно приходили за 1,4 с вместо 3,3 с, а за 5 с — у 31 раздачи из 32 вместо 26.
- **Запасные раздачи ищутся одновременно, а не по очереди.** Если данных нет 8 с (или подключено много пиров, а данных всё нет — признак пиров Zona), параллельно добавляется следующая подходящая раздача, через 10 с — ещё одна; играет первая, у которой нашлись данные, остальные закрываются. Ни одна раздача не бросается на полпути, на экране — сколько пиров и раздач ищется.
- **Ожидание — до 75 с** (раньше ошибка была уже через 10–64 с), без запасных раздач — до 2 минут. Если данных так и нет, «Повторить» продолжает поиск со всеми уже найденными пирами.
- В **Диагностике** видно, какой движок работает, сколько ждали данные и какая раздача их дала.

### Что нового в 0.12.1 — новая иконка и движок быстрее

- **Новая иконка «Кадр»**: кадр киноплёнки с кнопкой воспроизведения в фирменном синем цвете. На iOS 18 и новее есть тёмный и тонированный варианты — иконка меняется вместе с оформлением экрана «Домой».
- **По Wi‑Fi — до 100 пиров** (было 60), в мобильной сети — до 60 (было 40), в режиме экономии — до 30. TorrServer качает одновременно столько кусков впереди воспроизведения, сколько у него соединений, поэтому буфер наполняется быстрее и остановок меньше.
- **Фильм стартует быстрее.** Пока открыта страница фильма, по Wi‑Fi заранее скачиваются первые 16 МБ файла (было 8) — первые секунды уже готовы к нажатию «Смотреть». Плеер по Wi‑Fi начинает играть, накопив 2 секунды видео вместо 3, — так же быстрее и каждая перемотка.
- **Конец файла качается вместе с началом** и тогда, когда фильм запущен не со страницы (например, из «Продолжить просмотр»): у части MP4 и AVI индекс лежит в конце, и плеер больше не ждёт его отдельно.
- **Следующая серия готовится целиком**: за полторы минуты до конца серии по Wi‑Fi скачиваются начало и конец следующей (раньше — только первые 256 КБ), поэтому она включается сразу.
- **Запасной список трекеров** (пока движок не загрузил свежий из интернета или если GitHub не отвечает) — рабочие трекеры приложения вместо списка TorrServer по умолчанию с нерабочими адресами и retracker.local.
- Торрент-движок обновлён до **TorrServer MatriX.147.2** (исправления ошибок).

### Что нового в 0.12.0 — картинка в картинке, загрузки и субтитры из интернета

- **Картинка в картинке.** Кнопка ⧉ в верхней панели плеера сворачивает видео в маленькое окно поверх экрана: можно листать каталог, искать следующий фильм или выйти на домашний экран — видео продолжает играть. Кнопка разворота в окне возвращает в плеер, крестик — закрывает плеер. Чтобы окно появлялось само при выходе из приложения во время просмотра, включите **Моё → Настройки → Плеер → Картинка в картинке при выходе**.
- **Загрузки — смотреть без интернета.** В плеере **кнопка настроек → Скачать** (этот фильм, эта серия, весь сезон или все серии) или в **Раздачах** — удерживайте раздачу → **Скачать**. Ход загрузки, пауза, удаление и занятое место — в **Моё → Загрузки**. Скачанное открывается прямо с iPhone, даже в самолёте; субтитры из раздачи скачиваются вместе с видео. По умолчанию файлы качаются только по Wi‑Fi и встают на паузу, пока вы смотрите онлайн, чтобы не отнимать скорость у плеера. iOS не даёт торрент-движку работать в фоне, поэтому загрузка идёт, пока Кинотека открыта (для долгой — «Не гасить экран» в **Моё → Настройки → Загрузки**), и после перерыва продолжается с того же места.
- **Субтитры из интернета (OpenSubtitles).** **Кнопка настроек → Субтитры → Найти в интернете**: подходящие субтитры на выбранном языке — сначала точно подходящие к файлу (по хэшу), потом по названию раздачи и числу скачиваний; нажатие скачивает и сразу включает их. Можно включить автопоиск: если у иностранного фильма нет русской озвучки и русских субтитров, лучшие субтитры включатся сами. Нужен бесплатный ключ API OpenSubtitles: **Моё → Настройки → Субтитры** (там же ссылка и инструкция); вход в аккаунт необязателен — он увеличивает дневной лимит скачиваний.
- **Крестик снова закрывает плеер.** На iOS 26 «живое» стекло под кнопками плеера забирало касание, и «Закрыть» срабатывал не всегда — теперь это настоящие стеклянные кнопки, а плеер закрывается сразу, даже пока раздача ещё готовится.
- **Блокировка экрана доработана.** Замок блокирует касания, поворот экрана и системные жесты от краёв (Пункт управления, Центр уведомлений и «Домой» не срабатывают с первого раза). Коснитесь экрана — появится большой замок; нажмите его, чтобы разблокировать.
- **Компактное меню плеера.** Кнопка настроек открывает короткий список с текущими значениями справа — Раздача, Озвучка, Субтитры, Скорость, Пропорции, Синхронизация, Таймер сна, Скачать, Торрент; выбор открывается на отдельной странице, листать длинный список больше не нужно.
- **Настройки по группам**, как в настройках iPhone: Плеер, Качество и озвучка, Субтитры, Загрузки, Кинопоиск, ТВ-каналы, Поиск раздач, Торрент-движок, Данные и резервная копия, Диагностика — у каждой строки значок и текущее значение, а подробности — внутри.

### Что нового в 0.11.0 — работает без VPN, как Zona

Как работает Zona: её приложения не ищут торренты по названию на зарубежных трекер-агрегаторах, а спрашивают собственный поисковый индекс (Apache Solr). В нём каталог фильмов под id Кинопоиска и уже найденные для каждого торренты — с сидами, разрешением, языками дорожек и озвучкой, прочитанными из файлов, и статистикой «запустилось / не запустилось» у зрителей. Индекс и постеры размещены в России, поэтому отвечают без VPN, а сам торрент-трафик (пиры) не блокируется. Кинотека раньше зависела от серверов за рубежом (jac.red, API и постеры Кинопоиска), которые в российских сетях часто замедляют до обрыва ответа.

- **Раздачи из индекса Zona.** Для фильма из каталога торренты берутся по его id Кинопоиска — список не зависит от угадывания названия и года. Одновременно идёт поиск через Jacred; одинаковые торренты объединяются (название с трекера, сиды — наибольшие, озвучки из обоих). Без VPN первым отвечает индекс в России, через VPN — Jacred; второй источник ждём пару секунд, а если он позже — его раздачи добавляются в открытый список сами.
- **Лучше выбор раздачи.** Учитываются языки дорожек (раздачи только с оригинальной озвучкой — в конце списка) и статистика запусков у зрителей Zona: раздачи, которые часто не стартуют, предлагаются реже.
- **Каталог без ключа и без VPN.** Без ключа API Кинопоиска главная, каталог с фильтрами, поиск, страницы фильмов (описание, сезоны и серии, актёры, похожие) и страницы актёров берутся из индекса Zona. С ключом используется Кинопоиск, но если он не отвечает, отвечает медленно (дольше 4 секунд), исчерпан лимит или не принят ключ — на время включается индекс Zona.
- **Постеры без VPN.** Если постер с сервера Кинопоиска не пришёл за 2,5 секунды, загружается копия Zona (сервер в России), и следующие несколько минут постеры сразу берутся оттуда.
- **Проверка сети** (Моё → Настройки → Диагностика) теперь проверяет и каталог, постеры и раздачи Zona — видно, что работает без VPN.
- Настройка **«Индекс Zona»** (Моё → Настройки → Поиск раздач) — включена по умолчанию.
- **Обычные http-адреса больше не блокируются.** Из-за лишнего ключа в настройках iOS запрещала приложению все http-запросы (без https): плейлисты M3U и логотипы каналов по http, свой Jackett по http, а «Проверка сети» показывала ошибку App Transport Security у HTTP-ретрекеров. Сам торрент-движок это не затрагивало.
- **Понятный итог проверки сети.** Добавлен контрольный сайт ya.ru — он открывается в любой российской сети, даже когда оператор оставляет только «белый список» сервисов. Если не отвечает ни один сервер приложения, сверху появляется строка «Итог»: это ограничение мобильного интернета («белые списки») или интернет не работает совсем — приложение тут ни при чём.

### Что нового в 0.9.1 — торрент-движок снова работает стабильно

- **Шифрование больше не обязательное.** В 0.9.0 в мобильной сети движок соединялся только с пирами, которые поддерживают шифрование, и у многих раздач их почти не оставалось. Теперь, как обычные торрент-клиенты, движок сначала предлагает пиру зашифрованное соединение, а с остальными соединяется без шифрования. Строгий режим остался: **Моё → Настройки → Торренты → Шифрование трафика → Всегда**.
- **Движок не перезапускается без нужды.** Перенастройка под сеть закрывает все раздачи и переподключает движок, поэтому теперь она происходит только при настоящей смене сети (Wi‑Fi ↔ мобильная, режим экономии данных) и только при открытии страницы фильма, когда ничего не играет. Включение и выключение VPN больше не перенастраивает движок: IPv6 и UPnP, которые на iPhone не помогают, выключены.
- **Без сбоев во время перенастройки.** Пока движок переподключается, приложение не шлёт ему запросы: раньше раздача, добавленная в этот момент, могла не запуститься или уронить приложение. Если торрент-клиент движка не подключился, приложение переподключает его само и повторяет запуск.
- **Свой порт.** Движок работает на порту 48090 вместо стандартного 8090, который может занять другое приложение с TorrServer; если порт занят, берётся следующий.
- Настройка движка проверяется сразу после запуска приложения, а не при первом просмотре; свободное место под буфер определяется без подвисаний интерфейса; в журнал диагностики пишутся ошибки добавления раздач, порт движка и время перенастройки.

### Что нового в 0.9.0 — скорость и работа без VPN

- **Торрент-движок настраивается под сеть.** По Wi‑Fi буфер раздачи хранится на диске — до 2 ГБ, в зависимости от свободного места (раньше 64 МБ в памяти), и движок держит до 60 пиров: чем больше буфер впереди, тем больше кусков фильма качается параллельно и тем меньше остановок. В мобильной сети — буфер до 256 МБ, только TCP (UDP операторы режут чаще), ограниченная отдача, чтобы она не душила загрузку, и **шифрование трафика**, чтобы оператор не распознавал и не замедлял торрент. В режиме экономии данных буфер минимальный. Настройка меняется сама при смене сети и только при запуске новой раздачи — играющий фильм не прерывается. Буфер удаляется при закрытии раздачи и при следующем запуске.
- **Быстрый старт.** Пока открыта страница фильма, движок не только подключает раздачу, но и заранее скачивает начало и конец видео (там заголовок и индекс, которые плеер читает до первого кадра).
- **Больше пиров.** Ко всем раздачам добавляются российские ретрекеры (rutracker, corbina.net) и надёжные открытые трекеры — пиры находятся быстрее, даже если в magnet-ссылке трекеров нет.
- **Поиск раздач без VPN.** jac.red находится за границей, и в мобильной сети его ответ часто обрывается. Теперь поиск сам переходит на зеркала в России — jr.maxvol.pro и jac-red.ru, в мобильной сети сразу спрашивает зеркало, а ответивший сервер запоминается на несколько часов. Свой сервер Jackett/Jacred, указанный в настройках, не подменяется.
- **Моё → Настройки → Диагностика → Проверка сети.** Показывает, что открывается в текущей сети: Кинопоиск, постеры, каждый сервер поиска (с пометкой «ответ оборвался после N КБ», если оператор замедляет), HTTP- и UDP-трекеры, DHT, а кнопка «Проверить скорость торрента» скачивает часть открытой раздачи Ubuntu и показывает реальную скорость и на какое качество её хватит. Отчётом можно поделиться.
- **Плеер → ⚙︎ → Торрент**: скорость, пиры и сиды, объём буфера в реальном времени — видно, мало ли пиров у раздачи или скорость ограничивает сеть.
- **Настройки → Торренты → Шифрование трафика**: «В мобильной сети» (по умолчанию), «Всегда» или «Не требовать».
- Встроенный TorrServer обновлён до MatriX.145.1.

### Что нового в 0.8.0

- **Просмотренные серии.** Серия, досмотренная хотя бы до 90%, отмечается галочкой в списке серий и в списке файлов плеера. Кнопка «Смотреть» у сериала включает первую непросмотренную серию, а список сразу открывается на нужном сезоне. Долгое нажатие на серию — «Отметить просмотренной», «Просмотрено до этой серии»; кнопка «…» рядом с заголовком — отметить или снять весь сезон. Серии, которые ещё не вышли, показаны с датой выхода.
- **Страницы актёров и режиссёров.** Нажмите на человека в блоке «Режиссёр и актёры» — откроются его фильмы и сериалы (роли, режиссура, сценарии…), лучшие по рейтингу первыми.
- **Плеер:** двойное касание слева или справа — 10 секунд назад или вперёд (каждое следующее быстрое касание добавляет ещё 10); **⚙︎ → Синхронизация** сдвигает звук и субтитры, если озвучка отстаёт; касание общей длительности показывает оставшееся время.
- **Поиск** делит найденное на фильмы и сериалы, а запрос сохраняется в «Недавних», когда вы открыли результат. **Каталог** запоминает фильтры и показывает выбранные жанр и страну.
- На карточке «Продолжить просмотр» видно, сколько осталось, а долгое нажатие открывает страницу фильма.
- Исправлено: фильм с дополнительными материалами в раздаче не отмечался просмотренным и ломал смену качества; после последней серии раздачи «Продолжить» запускал её заново; большой плейлист из файла подвешивал интерфейс; кэш Кинопоиска рос без ограничений (ответы старше двух месяцев теперь удаляются).

### Настройки (Моё → Настройки)

- **Поиск раздач**: качество и озвучка по умолчанию, автокачество по сети, предварительная подготовка и автоматический запасной вариант. Запросы к Jacred идут через общую очередь; после HTTP 429 приложение выдерживает паузу, повторяет запрос или спрашивает зеркало и использует сохранённые результаты.
- **Торренты**: шифрование трафика и текущая настройка движка (буфер, число пиров, протоколы).
- **Плеер**: автоматическое восстановление зависшего потока, переход на более лёгкую раздачу после повторных сбоев, подготовка начала следующей серии и жесты управления.
- **Резервная копия**: экспортирует медиатеку, прогресс, историю, свои раздачи и обычные настройки. API-ключи и адрес M3U в файл не включаются.
- **Диагностика**: локальный журнал событий плеера и движка, память, зависания, сбои прошлых запусков и системные отчёты MetricKit можно вручную отправить через «Моё → Настройки → Диагностика → Поделиться отчётом». Ничего не отправляется автоматически.
- **Плеер → Звук в фоне**: если свернуть приложение или заблокировать iPhone, видео продолжит играть звуком (как в VLC), пауза и перемотка — на экране блокировки. «Картинка в картинке» недоступна: VLCKit 3 её не поддерживает.

### Если приложение вылетело

Начиная с 0.7.0 при следующем запуске появится окно «Сбой прошлого запуска» с кнопкой **Поделиться отчётом** — отправьте файл (например, в Telegram). Его же можно отправить позже: **Моё → Настройки → Диагностика**. Системный отчёт iOS лежит в **Настройки → Конфиденциальность и безопасность → Аналитика и улучшения → Данные аналитики** (файлы `Kinoteka-…`); к каждой сборке в Releases приложен `Kinoteka.dSYM.zip` для их расшифровки.

Что изменено в 0.7.0 ради стабильности:

- Торрент-движок больше никогда не перезапускается внутри процесса: остановка TorrServer закрывала его базу настроек, и следующий запуск ронял всё приложение.
- Плеер VLC освобождается в фоне только после полной остановки — закрытие плеера и смена серии больше не подвешивают интерфейс до принудительного завершения iOS.
- Изменение пропорций и обрезки видео выполняется вне главного потока; повторная загрузка того же потока при восстановлении начинается с нужного места.
- Меньше расход памяти: компактные кэши постеров и ответов, освобождение кэшей и заранее подготовленной раздачи при нехватке памяти, плейлисты разбираются в фоне.
- Медиатека сохраняется в фоне и не обрывается при сворачивании; повторяющиеся записи (из старых копий, плейлистов, Кинопоиска) отбрасываются.
- Значения от сервера (Retry-After, позиции, длительности) проверяются, чтобы не приводить к аварийному завершению.

### Почему стало быстрее

- Раздачи ищутся сразу при открытии страницы фильма, а не после нажатия «Смотреть»; результаты хранятся на устройстве (открытый раньше фильм показывает раздачи мгновенно, даже если сервер поиска не отвечает), одинаковые запросы не дублируются.
- **Готовить раздачу заранее** (включено по умолчанию): пока открыта страница, раздача, которую включит «Смотреть», уже подключается к пирам — после нажатия видео стартует без ожидания «Получение данных торрента…». Тратит немного трафика; выключается в настройках.
- Данные фильма, сезоны и актёры с Кинопоиска загружаются параллельно; готовность торрента проверяется чаще.
- Одинаковые одновременные запросы к Кинопоиску объединяются, поэтому несколько рядов не расходуют лимит повторно.
- Торрент не закрывается сразу после выхода из плеера: TorrServer держит его ещё 3 минуты, поэтому повторное открытие или следующая серия стартуют быстро.
- Постеры декодируются в размере экрана, поэтому каталог расходует меньше памяти при быстрой прокрутке.
- Приложение измеряет время до первого кадра и постепенно отдаёт приоритет раздачам и трекерам, которые лучше работали именно на этом iPhone.

## 3. Сборка (без Mac)

Сборку выполняет GitHub Actions (`.github/workflows/build.yml`) на macOS-машине GitHub (macOS 26, Xcode 26 — он нужен для Liquid Glass) при каждом пуше в `main` или вручную: **Actions → Build iOS app → Run workflow**. Версия Xcode и SDK пишется в комментарий о готовой сборке и в описание релиза.

- Успешная сборка публикуется в **Releases** как файл `Kinoteka.ipa` (без подписи).
- Если сборка упала, создаётся Issue «Ошибка сборки …» с выдержкой из лога.
- Ход всех сборок (запуск, готово, ошибка) пишется комментариями в Issue #1 «Статус сборок».

- Пуши в ветки `feature/...` тоже собираются, но публикуются как **тестовые** (pre-release) сборки; основной релиз — только из `main`.

Проект генерируется через XcodeGen из `project.yml`. Зависимости: VLCKit (Swift Package `tylerjonesio/vlckit-spm`) и `TorrServerKit.xcframework` (скачивается из релиза TorrServer во время сборки).

### Тесты

Логика без интерфейса (разбор серий в именах файлов, M3U-плейлисты, названия раздач, ответы Jacred/Jackett, выбор лучшей раздачи) лежит в `Sources/Core` и проверяется тестами из `Tests/` командой `swift test` (работает и на Linux). В GitHub Actions тесты запускаются перед сборкой.

## 4. Установка на iPhone с Windows (Sideloadly)

1. Установите iTunes и iCloud **с сайта Apple** (не из Microsoft Store), затем [Sideloadly](https://sideloadly.io).
2. Подключите iPhone кабелем, нажмите «Доверять этому компьютеру».
3. Перетащите `Kinoteka.ipa` в Sideloadly, введите Apple ID (лучше отдельный) и нажмите **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → доверьте профилю разработчика.
5. Включите **Настройки → Конфиденциальность и безопасность → Режим разработчика** и перезагрузите телефон.

С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней (в Sideloadly есть автообновление по Wi‑Fi). Альтернативы: AltStore или SideStore.

Требуется iPhone с iOS 18 или новее (этого требует TorrServerKit). Приложение собирается только для iPhone.
